**结论：未发现阻断性问题或重大题意缺陷；有一项次要信息语义补充建议。题目可进入用户审核。**

本轮独立运行 `check_inputs.py` 与对照方案的 `check_plan.py`，均通过。输入检查确认环线、车队、请求、路段时轴、配对样本共同前缀及逐字节重现；方案检查仅确认声明的组件归属与动作范围。本审阅没有另写第三套车辆仿真，不能把这些PASS当作运行表现、完整物理可行性或因果性充分证明。

## 2. 非交通专业本科生能否理解

题面先用“上游坐得较远，下游连续上不去”的日常现象引入座位周转，再给出明确的环线、座位、先下后上、站停耗时和队列规则。图示仅表达站点先后关系，节点名称用于辨认功能区，未要求学生从校园图片推导准确道路距离。理解研究对象不需要先掌握公交专业术语。

乘降时间、空位预留、行时和评价口径均有直接定义。学生仍需自行组织车辆、在车目的地人数、候车与服务中状态之间的关系，建立可复现的全过程模型，并说明计划、信息和控制之间的联系。题面没有将研究简化为调用一个现成最短路或优化函数。

技术说明较密，特别是事件顺序和信息边界，但这些内容是保证不同实现比较公平所必需。数据字典可与题面配合阅读；建议发题时完整保留，不能只发一张环线图或节选任务页。

## 3. 关键定义逐项检查

| 项目 | 审阅判断 |
|---|---|
| 两校区与地理依据 | 两个车队分别研究；地图仅提供功能分布，不作为现行路线、路权、车数、行时或交班制度的实测证据，界限清楚 |
| 车辆与乘客 | 一人一次请求、固定起讫站、不弃乘与不换乘；座位上限及在车者不得被强制清空均明确 |
| 乘降与事件顺序 | 本次候选队列在到站时冻结，选中后进入服务中，完成乘降有规定时刻；同秒乘客与车辆、同秒多车的顺序已定义，不会依赖程序容器的偶然顺序 |
| 预留与控车 | 预留按下车后的余载和当前可分配队列计算，仍遵守先进先上；附加等待仅限指定控制站，关门后不再上客 |
| 固定与动态等待 | 动态等待替代原固定等待，不允许叠加；首次投入与离站的含义也有区分 |
| 决策时刻 | 预留、控车和是否交班在本次到站时一次决定；本次乘降完成时刻由已知人数与所选动作确定，不是等待未来观测后重新决策 |
| 交班实际发生 | 交班在本次乘降完成后立即执行，完整交接须落在允许窗口内；司机系数在完成后更换，乘客保持在车，车辆不能瞬移或重置 |
| 司机到期 | 未完成交班而越窗的安排应判不可行，不能靠让原司机继续运行来伪装合格；题目允许研究不合格对照并说明原因 |
| 当前与历史信息 | 本车本站即时字段有明确清单，其他信息来自延迟的已发生历史；没有把全网实时队列或乘客逐人目的地、期限暗含为控制输入 |
| 回放与因果 | 完整验证文件用于环境回放及事后评价，不能因为文件公开就提前读未来真值；共同输入前缀检验是必要条件，检查程序未将其冒称充分保证 |
| 观察终点与人数守恒 | 未上车、服务中、在车及已完成状态分别处理，终点未完成者保留在按时率分母和未完成统计中；截断耗时定义避免只统计成功旅客 |
| 效率与下游服务 | 全体指标、起点尾部等待、在车耗时和未完成请求均须报告；不能仅以满载率或上车人次断言改善 |

上述定义相互一致。特别是“到站时作决定”和“乘降完成后执行交班”属于两个不同事件；当前文本与数据字典已将其区分，不应在程序中把交班时刻随意推迟到等待结束，或反过来允许在等待期间重新挑选乘客。

## 4. 次要建议与仍需保留的局限

### 次要建议 M1：报告按实际事件发生进入历史

“已发生报告”和“历史事件”的现有措辞可以正确理解，但建议再明确一句：到站观察在实际到站后形成，离站记录须实际离站后形成，尚未发生的离站或交班完成记录不能提前装入到站历史。同一秒也只能使用按题设顺序已经处理过的事件。

这属于信息口径的编辑补充，不是要求增加传感器或改变控制动作。它有助于防止学生将一整条含未来离站字段的访问记录，按到站时间一次性发布给调度器。若仅根据现有字段推算计划中的完成时刻，应与读取未来真实事件记录区分。

### 模型与落地边界

- 问卷只有一条定性建议，不能据此估计总体需求、真实车型容量、车队规模或现行运营制度。附件对此已有明确说明。
- 队列冻结、线性乘降用时、忽略车辆与站台阻塞、独立接班人员均是简化，适用于规定研究工况；它们不能自动成为实际运营规律。
- 公开动作日志检查只核声明、范围与共同前缀，不核完整车辆事件、服务表现或源程序是否偷读未来。题面和字典没有夸大其作用，正式评阅仍须检查模型与程序。
- 有限规划及验证样本支持方案比较，但不能保证任意天气、活动规模或长期需求变化下均可行。改变约束后，需重新检查容量、司机资源与终点积压。
- 两校区均被纳入研究，不等于同一组数值结论可直接搬用。真实试运行前，应分别核实路线及资源，并用匿名的到离站、乘降与起讫资料检验模型。

这些局限已在学生任务中转化为实际验证要求，不妨碍它作为一题基于校园诉求的研究训练题；若将计算结果直接宣称为可立即部署的校方调度方案，则证据仍不足。
