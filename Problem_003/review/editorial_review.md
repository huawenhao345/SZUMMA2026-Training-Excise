# 题面文字与排版检查

版本：初稿2026-10-14，用户于2026-10-20审核通过后的提交版。本题按“背景与系统—研究任务—附件与说明”排为三页，没有在四问前冠以建模步骤或算法名称。

开头直接交代运输对象、装置怎么工作，以及为什么需要比较限速与发热。技术条件用正常叙述给出，较长的数值表移至附件。四问分别改变恒温、有限线路、重复运行和接线状态；没有用一套重复动词把各问写成教学提纲。

本轮文字修订包括：

- “速度峰谷、入口相位选择”不再用于理想正常三相；这项修改来自机制审查，不能靠措辞保留一个不成立的研究任务。
- “每相”电阻与整套热容、费用分别明确；补充相电流正方向，降低符号约定带来的专业门槛。
- 回程、尾电流与温度继承写在操作条件中；第四问只检查到达停车，避免与第三问末趟360秒考核混淆。
- “允许下行”的量词改为对全部未知初始电角度和题给入口速度均满足限制，不能仅找一个有利初态。
- 附件不给断相回路的计算结论；只描述连接条件，保留参赛者建立电路和运动方程的工作。
- 长文件名分行，引用采用可点击名称与 DOI，避免 URL 在正文中断成不自然片段。

题面中保留了必要的理想化条件。文风调整不能替代对磁链、互感、传动、热量归属与停歇过程的检查；数值证据及适用边界见质量报告。

最终排版检查使用两遍 XeLaTeX、中文抽取和页面文字坐标检查，并逐页查看图像。用户审核通过后，将页眉“审核稿”改为“原创模拟题”，同步交付检查并重新编译；PDF 与 LaTeX 源稿均为同一提交版本，题面任务和参数不变。
