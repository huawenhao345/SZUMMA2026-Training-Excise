# Problem_003 命题质量报告

题目：**山地货运轨道车的无源限速**。版本：2026-10-14用户审核稿。本次先交付独立审核分支，待用户审核后再创建 PR。执行者自审 **87/100**，独立题面审阅 **86/100**；协作审阅由另一 AI 代理完成，不冒充外部人类专家或竞赛组委会认证。

## 1. 现实矛盾与研究对象

重力驱动的下坡运输不依赖牵引供电，却必须在载荷和坡度变化时控制车速。永磁发电机接固定电阻可消耗机械能，但感应电流、绕组电阻、转速和温度共同决定响应，不能把“有制动力”当成“所有初态都能稳定限速”。电阻箱分担发热，也会改变运行表现；更强散热与传动改造还有质量、费用和运输时间代价。

本题针对拟试制装置提出设计工况，不称其为已经运行的实机。数据是题设参数，不提供运行样本，不要求回归、分类、预测或现场采样。数学工作来自电路、受力、能量、稳定性与状态继承。

## 2. 原创性与相似性

近2016—2026年官方目录重新核查，代表性机理题及公开评阅摘要的实际读取边界详见 [调研记录](research_review.md)。最接近的历史赛题包括2009国赛A制动器试验台控制、2022国赛A波浪能阻尼设计，另有2026 USAYPT涡流制动现象题。本题没有复用飞轮补偿与采样控制，也不把平均发电功率最大化作为任务。

永磁机短路/负载制动及内外热分配已有实验和专利研究，不能声称基础机制是新发现。本题的原创部分是独立构造的两条等降高有限线路、固定组件对连续载荷的适用性、两热体的十趟状态继承，以及正常前史后的放行前断相。未复制第三方参数表、实验记录、图文或求解代码。相似性结论限于已查目录、已读资料和关键词检索，不是全球排重证明。

仓库前两题分别研究低用水管网水质和苹果授粉安排；本题不复用其反应输运、参数拟合、访花来源过程或数据结构。新增范围仅 `Problem_003/`。

## 3. 四问的数学研究与基础路径

| 问题 | 核心数学工作 | 本科基础路径及局限 | 深入研究空间 |
|---|---|---|---|
| 1 | 从电路和能量建立机电动态；限速状态存在、稳定性及初态适用范围 | 直接建立电流与运动关系，比较均匀坡道；不能只把某个平衡速度代入即称稳定 | 无量纲量、状态吸引范围、近似稳定性与完整动态的关系 |
| 2 | 有限路长、坡段位置、两处发热与阻值变化 | 首趟积分并核受力/能量；长期结论不等于整段峰值限制 | 模型降阶误差、进入/离开陡坡的状态、热反馈与末端表现 |
| 3 | 固定选型、重量/费用、连续初态范围与跨趟热状态 | 合法组件组合与有限候选比较；每趟需含停车尾电流和冷却，不重置温度 | 连续工况的界、热循环映射、性能余量、搜索范围与计算效率 |
| 4 | 接线改变后的动态、前史温度、未知电角和允许集合 | 从剩余连接重建模型，复核候选运行范围；不得把少数有利相位当全范围保证 | 未知初态的上界、降额边界、不可行证明、相位平均的误差 |

各问使用前面的模型和第三问的方案。第四问改变的是电路结构，不是添一份数据；两个星点和开断时机明确，避免隐含零序或电弧模型。题面给物理对象的磁链、电感和热参数，没有给完整运动方程、制动力表达式、降阶步骤或参考选型。

非电气本科生需要基本电磁感应、基尔霍夫定律、牛顿运动和能量关系。磁链、相电流正向与接线已说明，不需电机控制课、有限元电磁软件或厂家数据。基础队可用直接积分和有限方案比较；强队可研究稳定性、降阶误差、连续工况界与故障运行集合。

## 4. 参数与附件检查

附件为五个机器文件：两份JSON、三份CSV。CSV共 **19行**（路线12、齿轮4、散热3）。全部标为设计参数与工况，未编造实测来源。生成器无随机观测，只整理题设；没有轨迹、优化结果或隐藏整车求解器。

最终 `check_inputs.py` 检查字段、数值范围与单位、电感对称正定、两线路长度与降高、角度插值、组件表、发车/回程时序及故障前史；五文件逐字节和SHA-256与确定性重生成相同。故意损坏的 **8种**输入副本均被拒绝，包括非正定电感、时序冲突、错误故障前史、载荷继承、路线降高/端点、纯字节漂移和将故障全初态要求改为存在性。另核3个合法选型费用质量，拒绝8种非法选型。临时副本和测试设计不上传。

矩阵保留自感与带符号互感，未将三个裸自感错当有效平衡电感。每相铜阻与外阻、两热体总量、齿轮比与反射惯量分别定义。价格和散热参数是比较边界，不冒充采购或实机热标定。

## 5. 最终可解性与数值验证

完整参考原型只在临时工作区试算，公开材料不附推荐选型数值、轨迹、故障载荷界或完整求解程序。

已验证恒温均匀坡道研究可以建立，平衡计算残差小于 **7×10⁻¹² N**，并用完整机电动态的线性化核查局部稳定性。第二问的四个冷启动工况均能计算到终点，有限坡道确实会使只依据长缓坡结论的判断失效。结果不是依赖拟合出来的经验制动力。

最终设计筛查覆盖 **72组十趟工况**：六类固定装置，每类检查两线路、三个载荷点和两个入口速度端点。四类装置在这些受检工况中满足全部限制，两类提供性能或积热不通过的对照；存在费用、时间、散热和余量的实际取舍。这里证明有基础设计路径，**不认证连续载荷、入口速度的全域覆盖，也不声称全局最优**。参赛论文仍须为其适用范围和余量提供依据。

两种独立编写的实现分别采用正常对称条件下的坐标表示与原始三相节点约束。三个完整正常案例的对照，车速差不超过 **3.7×10⁻⁶ m/s**，热体温度差不超过 **1.8×10⁻⁶ K**，到达时间差不超过 **1.6×10⁻⁵ s**；独立能量账的相对误差不超过 **1.5×10⁻⁸**，星点电流和约束误差不超过 **3.7×10⁻¹² A**。相电流轨迹对累计转角更敏感，没有将车速吻合误写为全部电流逐点都达到同一精度。

断相程序使用实际剩余连接与完整电感定义，保留未知初始电角；先完成12个不同载荷、线路、相位的完整运行，再对另一候选完成8个线路、入口与相位组合，使用相应九趟前史温度。断相独立能量账的相对误差小于 **2×10⁻⁹**。存在正常可用但断相后不宜下行的反例，也存在经过降额检查的可行候选，因此没有预设“降载必能解决”或“所有选型都必停”。有限相位试算不是全相位认证；具体允许集合留给参赛者研究。

主路径按每个坡度节点分段计算，确保不跳过短陡坡；段间六个状态完全连续，全部五个内部/末端位置节点均到达。减小积分公差后的受检到达时间变化不超过 **4×10⁻⁵ s**；加密峰值检查的速度变化不超过 **0.002 m/s**。这些是算法与模型内部一致性的证据，不是装置现实预测精度。

分段修复后60组十趟筛查约 **173秒**，追加12组约 **35秒**，主路径峰值内存约 **65 MiB**。独立原始三相实现的15段核验约 **422秒**；追加的分段对照与故障核验约 **206秒**，8组合故障复核约 **101秒**。环境为Python3.12.14、NumPy2.3.5、SciPy1.17.0、Linux CPU，限制BLAS单线程。基本求解在普通本科设备上可行；不保证任意细密全参数搜索耗时相同。公开辅助程序仅需Python标准库。

## 6. 发现的问题与修订

| 发现的问题 | 处理 |
|---|---|
| 小空气芯拾取线圈低速非线性缺少合理器件支持 | 否决初选结构，改用轮轴驱动旋转永磁发电机；参数仍诚实标为设计值 |
| 理想三相正常工况的入口相位只是坐标选择 | 删除正常相位设计；只有断相工况引入未知电角 |
| 铜阻、外阻焦耳热归属容易混用 | 分成电机与电阻箱两个整体热体，各给热容/散热与质量费用 |
| 惯性和互感容易被无说明忽略 | 给轮轴/转子惯量及完整正定电感矩阵，不把裸自感直接充当三相有效值 |
| 停车直接清零电流会丢失储能 | 规定锁转子、保持闭路、尾电流发热和随后冷却，温度跨趟继承 |
| 自适应步长曾跨过短陡坡导致偶发时间偏差 | 改为逐坡度节点分段与适当步长控制；全部设计筛查重做，另由原始相变量核对 |
| 故障开断瞬态和允许范围量词可能含糊 | 改为放行前已断开；明确对全部未知电角与题给入口速度均满足限制 |
| 故障温度考核终点不明确 | 写明到达终点停车，第三问仍包含末次放行后的360秒 |
| 正式文字与文件名排版偏密 | 第三问自然分段，长附件名分行，引用改为可点击名称与DOI |

修订未通过向学生提供制动力公式、推荐模型或答案来弥补缺陷。旧自适应筛查不作为最终设计证据。
