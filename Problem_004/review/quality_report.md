# Problem_004 命题质量审查报告

审核稿，2026-10-21。题名：《轻型屋盖的积水与排水》。本报告由本轮命题执行者自审，并以两种分别实现的数值离散交叉核对；没有另称外部专家独立审定。报告公开，省略参考解答、具体可行组件组合、顶撑推荐时刻、临界刚度数值与求解轨迹。

## 1. 选题及现实意义

轻型屋盖积水时，变形既影响水荷载，也改变可蓄水空间、排水口高程及区间交换。增加排水能力、改变排水位置、加固梁和临时顶撑所改变的对象不同，不能仅比较一个总积水量或一次静力挠度。

Marino的历史论文说明积水与结构变形之间的反馈；Blaauwendraad、Colombi的书目及可访问摘要明确其已有研究基础。CROSS报告969提供排水维护与积水事故的实际背景。它们支持研究对象的真实性，未提供本题数值参数，也不构成本题符合现行规范的证据。参考资料的实际阅读范围逐项记录在 [调研报告](research_review.md)。

候选比较如下。评价是命题取舍，不是给现实研究方向排优劣。

| 候选 | 数学结构与训练潜力 | 主要问题及取舍 |
|---|---|---|
| 多孔物料堆自热 | 反应、传热、氧输运及有限物料 | 标准几何临界自热已有成熟结果，增加通风参数易落入论文复算；与第三题的热机制距离不足。退选。 |
| 气体缓冲与被动吸能 | 压缩、传热、阻尼及冲击过程 | 数学入口可行，但与第三题被动装置的结构较近，未继续发展。 |
| 细土—粗层毛细屏障 | 非饱和流、界面突破及侧向排水 | 物性及边界封闭负担较重，简单参数表不足以支持突破机制。作为备用。 |
| 轻型屋盖积水与排水 | 变形与水面共同决定荷载，有限进水及接触改变边界 | 本科可建立梁和水量模型，又可深入稳定性、湿干边界与单向接触。选用。 |

先检查仓库主分支及前三题资料。前三题分别研究低使用率管网水质、果园授粉、轨道车无源限速；第四题不沿用其状态模型、附件或研究任务。

本轮复查2016—2026 CUMCM官方发布目录及COMAP A—F矩阵，精读或按记录范围复核2020 MCM B、2021 MCM A、2018 CUMCM A，另查1993 MCM B这一自热候选的重要近邻，并查看公开展示论文和评阅摘要。没有宣称已展开所有年度题包或读过付费讲评全文。

以屋盖、积水、挠度、排水、ponding、roof instability等词定向检索，未在所核范围找到与本题同构的CUMCM/MCM/ICM题面。该结论有检索与访问边界，不是全球原创性证明。积水反馈、定水量/定水位的区别、梁理论和接触本身都是既有知识；本题的原创性在于独立构造双区有限进水、随动排水口、预算改造及运动顶撑的连续研究情境，未移用论文算例的参数、图表或结论作为答案。

## 3. 数学结构与任务依赖

| 问题 | 需要学生完成的研究 | 与后续的联系 |
|---|---|---|
| 第一问 | 从变形后的水深构造水荷载和静力平衡；辨别总水量约束和外接水箱的水位约束；提出物理稳定性判据 | 确立水面、湿干范围与梁变形的关系，并区分平衡、稳定和使用限值 |
| 第二问 | 用两区水量连接结构平衡、交换与排出；比较同总入流、不同空间分配；检验固定初始屋面的近似 | 获得永久改造需要比较的全过程状态与评价量 |
| 第三问 | 在连续面积、离散位置及加固选择下比较费用与多项约束，给出对三种工况通用的方案 | 为应急情形固定一套永久设施，避免每问重新换一套对象 |
| 第四问 | 处理堵口事件、只能承压的移动接触和梁的正负弯矩；比较启动安排及排水后果 | 检验第三问方案在失效工况下的适用边界，不能用后续恢复抵销此前越限 |

题面现已解释结构力学术语并提供通用梁弯曲关系和端部条件，不要求选手事先学过结构力学。基本路径可采用少量结构自由度或常见梁离散，结合水量收支及分段时间计算。较强队伍可比较不同离散、研究稳定性与使用边界、处理接触与湿干转换、分析费用和约束的取舍，或给出设计范围内的充分检验。没有把某种机器学习或优化算法作为入口。

粗模型须检验空间分辨率，不能用一根线性弹簧取代全长后仍声称控制了所有弯矩；高精度模型也须说明物理与边界条件。数值迭代不收敛不等于屋盖失稳，求得一个平衡也不等于全过程满足限值。第一问的稳定性不能直接从固定水位试验套用于有限水量过程。

## 5. 初步求解与计算可行性

求解试算用于检查命题是否成立，完整求解实现和轨迹未纳入公开提交。没有把仓库内任何目录当作保密位置，也未建立或分发参考解答包。以下只给核查范围与误差，不给可直接复制的设计答案。

| 核查 | 实际范围与结果 |
|---|---|
| 静水闭合 | 三种指定封闭水量均求得可解释的平衡；另检验水箱维持水位时的刚度变化，分别检查稳定性及使用限值 |
| 解析对照 | 干梁均布荷载挠度与解析表达的最大差小于 `9e-9 m`；固定水位辅助问题的临界刚度检验相对差小于 `4e-9` |
| 不同结构离散对照 | 16个静水状态，包括无水、偏载、两侧有水、接触及脱离；模态实现与另写的三次梁有限元实现交叉核对，水位也分别采用不同实现求取 |
| 静态最大差 | 挠度小于 `4.4e-7 m`，水位小于 `9.8e-7 m`，弯矩小于 `2.6 N·m`，顶撑反力小于 `1e-4 N` |
| 有限入流试算 | 39个完整90分钟过程：15个正常工况、24个堵塞及顶撑工况；另有3个固定在初始干梁形状的对照过程 |
| 设计非空性 | 两档预算分别至少找到一套对U、L、R均满足正常挠度、正负弯矩及末期水量限值的方案；未声称全局最优，也不规定学生须找到同一方案 |
| 应急约束有效性 | 既有满足条件也有反力越限的启动试样；检验包含顶撑前时段。尚未对整个连续启动区间作穷尽认证 |
| 守恒 | 正常、堵塞及顶撑过程均核对总入流、总排出及两区蓄水，累计水量不平衡小于 `1e-12 m³`；交换不产生净水量 |
| 加密检查 | 选3个代表过程，将24个模态、每区96个积分点及5秒步长，加密为32个模态、每区160点及2.5秒步长；峰值挠度差小于 `1e-6 m`、弯矩差小于 `0.4 N·m`、反力差小于 `0.2 N`、末期水量差小于 `2e-5 m³` |
| 接触与水区抽查 | 从39个过程中复算273个时刻，未发现负水量，每区至多一个连通湿区；支柱穿透量小于 `3e-17 m`，反力与分离间隙乘积绝对值小于 `5e-14 N·m`。这是抽查，不是任意方案下的全域结论 |
| 资源 | 上述39个过程及3个加密对照的主验证批次在本轮环境中约212秒、峰值内存约70 MiB；这是算例实测，不能保证任意优化搜索同样耗时 |

两套静力实现均由本轮执行者编写，属于不同离散和程序的交叉检验，不是两位独立研究者的认证。有限样本试算证明至少存在可行研究路径，不证明任意选型的可行性、不排除其他平衡分支，也不给出连续设计域的最优性证书。

## 6. 审查发现与修订

| 发现的问题 | 已采取的修订或处理 |
|---|---|
| 单一水池、固定水位的积水梁容易变成经典教材算例 | 增加有限入流、两个水区、随动隔坎和排水，再引入单向运动顶撑；四问始终研究同一屋盖 |
| 两区不连通时共用水位会强加不存在的约束 | 明确每区独立水位，只能经给定槽交换；槽顶随梁运动 |
| 排水口固定在地面高程会漏掉主要反馈 | 明确排水口与唇口随当地屋面运动；费用和候选位置均在题面给出 |
| 正常初态可能被误当成无挠度水平梁 | 明确初始无水但有永久荷载；固定屋面对照用干梁形状 |
| 顶撑会产生负弯矩，且可能与梁脱离 | 给出仅承压、可分离的物理条件，正负弯矩都检查绝对值；端部锚固允许上拔 |
| 初定顶撑反力上限在试样中一直不活跃 | 经试算收紧为5000 N，使启动安排需要实际比较；仍保留应急可行研究路径。该值是题设比较限值，不是设备额定值 |
| 将正常残余水量限值硬套堵口情形，可能让应急问题只剩“无解” | 应急仍报告残余水量、评估排水作用，但通过条件为原挠度/弯矩限值及顶撑反力限值 |
| 顶撑前已越限却只报告顶撑后的改善 | 明确考察完整90分钟，此前越限不能抵销；同一启动时刻用于三工况 |
| 点力作有限项截断时会影响弯矩对照；支反力与位移单位相差大 | 命题验证改进点力表示和数值尺度，并与另一套有限元实现对照；这些属于验证实现修正，不放入学生题面 |
| 时间离散在堵塞时刻混用事件前后流量 | 按事件分段，明确时段端点条件，再复核堵塞及顶撑试样；不能以步长粗略掩盖输入跳变 |
| 题面容易写成“建模—优化—鲁棒性”教学清单 | 改用场馆改造的连续叙述，删除算法名称、预期结论及逐步求解提示，必要约定集中到系统说明和附件 |
| 用户指出术语与小图默认了结构力学背景，影响读题 | 改写横向刚性、支承、EI、线荷载和准静态等说明，补充通用梁关系及端部条件；改为受载挠度、平面布置和纵剖面三图，四页排版，并同步附件字典与检查 |

## 7. 难度、开放性与局限

建议96小时。本科基础路径使用题面提供的梁弯曲关系，结合水量积分和数值计算；学生需建立与变形相关的荷载和水量约束，不能仅代入一个现成的梁挠度公式。没有必须使用完整壳单元、流固CFD或非线性材料模型的门槛。四问的难度来自不同物理约束及其反馈，不靠增加算法名。

区分度主要在于：是否正确区分水位和水深；是否建立与真实湿润范围一致的荷载；如何给出稳定性依据；是否检验全过程与正负弯矩；近似的误差是否可控；设计是否在同一套条件下公平比较；应急判断是否同时解释结构和排水后果。第三问并未指定单一标量目标或唯一数值答案，可在费用、余量、排水与简洁性之间给出有根据的选择。

仍有以下局限。

- 一维线弹性梁、横向刚性和小挠度忽略真实屋盖的二维效应、连接、塑性与大变形。试算的小坡度检查只支持本题近似的数量级，不能推导工程安全认证。
- 区内水平水面与准静态假设忽略快速漫流、水流惯性及水体与结构的动力耦合。选手应检查其使用范围；若自行引入额外机制，应说明参数依据。
- 给定的双向交换式是集中近似；未描述槽口三维流动、淹没修正、杂物迁移及排水管网背压。题面明确按此式计算，以避免关键关系不封闭。
- 数值参数、费用和使用限值没有实物测量依据。真实性来自研究对象和守恒/力学结构，不来自虚构的工程监测。
- 原创性检索有范围限制。有限试样、空间/时间加密及离散对照不能代替所有分支、连续启动范围和全局设计域的证明。
- 公开附件可完全重现题设输入，不公开完整求解器。因此公开脚本的PASS只证明交付与输入一致，数值可解性证据来自本轮命题试算，仍应通过实际试赛进一步检查。
