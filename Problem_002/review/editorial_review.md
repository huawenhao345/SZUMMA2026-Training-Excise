# 题面文字检查

状态：2026-10-14审核稿。用户要求先审核第二题，再创建PR。本记录检查文字与信息安排，不声称通过了自动“AI文本检测”或真人盲评。

## 本次调整

正文以果园、相容花粉和合作社的安排为线索，不使用“基础模型建立”“决策价值”“鲁棒策略”等环节性副标题。四问直接写需要研究的对象和情形。建模的开放性体现于问题本身，没有在每问重复“可检验”“多路径”“不得使用某算法”等命题审查用语。

必要条件仍保留在题面：树位数和间距、两日开花窗口、访花轮次、改植与租蜂限制、初期坐果的时间口径。数据生成、独立分组、文件字段、计量与许可放在附件说明；质量评价和复杂方法只在审查材料中。正文未放入计算指标的整套公式、指定模型或解题思路。

| 检查项 | 实际处理 |
|---|---|
| 背景是否堆叠意义与价值宣言 | 直接解释为什么“蜂多、花多”不等于有效授粉，再给果园与决策主体 |
| 是否用空泛短语替代对象 | 使用树位、花期、花粉来源、初期果数、租蜂数量等具体量 |
| 问题是否像算法教学大纲 | 四问使用建立、估计、评价、给出、复核等设问，不罗列算法 |
| 是否为了简短而删去定义 | 数据口径和预算规则仍闭合，连续访问、同树换花、原树位花量均有解释 |
| 生物学术语是否超过对象门槛 | S型用一段给出判别规则，不要求遗传学课程背景 |
| 是否含不必要的反复免责声明 | 合成说明集中到附件与README；正文仅交代来源和模拟属性 |
| 是否出现含糊的愿景 | 用主栽初期果数和空间分布比较；不将初期坐果直接称为成熟果收益 |
| 是否依靠隐藏假设让任务“开放” | 源花粉、首访与时间窗口明确，未知的推广关系由队伍说明并检验 |

初稿“访花批次”改为“访花轮次”，避免工业流程式措辞；“适宜访花的天气连续几日较少”改为“连续几日不利于蜜蜂活动”，修正语义；附件标题单独起页，避免孤立在上一页末尾。

## 保留事项

数据条件依然有理想化成分，例如固定50次的一轮访花、统一活力和确定的开花窗口。这些属于比较方案需要的题设，不是通过文风消除的科学问题；实际边界见质量报告。

正文与附件共两页，正文一页完成背景、条件和四问。两页PDF已检查中文、公式符号、表格与链接。最终是否符合用户期望的文字风格仍以本次审核反馈为准；尚未创建PR。
