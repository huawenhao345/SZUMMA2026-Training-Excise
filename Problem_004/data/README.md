# 附件说明与数据字典

全部附件为**题设设计参数与规定工况，非实测数据**。费用不是市场报价，限值不是建筑规范条款。没有用观测值拟合的参数，也没有待预测的标签、推荐方案或隐藏的最优解。数值由 `../scripts/make_inputs.py` 确定性生成，无随机种子、外部下载或第三方数据依赖。

## 1. 共同约定

除 CSV 明确采用分钟、升/分钟外，几何及流量关系使用国际单位制。将升/分钟换成立方米/秒时除以 60000；将分钟换成秒时乘以 60。

| 量 | 定义 |
|---|---|
| `x` | 从左端沿梁量起的位置，m；左右区分别为 0—3 m、3—6 m |
| `w(x)` | 相对未加载水平梁的向下挠度，m；屋面高程为 `-w` |
| `H1`、`H2` | 两区水面相对同一零线的高程，m，可为负；不是水深 |
| 水深 | 所在区水面高程减去变形后屋面高程，负值取零 |
| 水量 | 真实水深在所属区条带上的体积积分，m³；不得把干区按负水深计入 |
| `Q12` | 过坎交换流量，m³/s，正值由左向右；在两区水量收支中符号相反 |
| `Q1`、`Q2` | 各自排出研究范围的流量，m³/s，无回流 |
| `EI`、线荷载 | 均针对整个 4 m 宽条带；永久线荷载不应再次乘以宽度 |
| 弯矩限值 | 正、负弯矩均以绝对值比较，单位 N·m |

每次计算一种工况均重新从两区水量为零开始。无水不等于无变形：初始梁承受永久荷载。无水区没有实际自由水面；可选择不高于区内最低屋面的计算水位，并保证其水荷载、排出流量为零。

梁两端竖向位移为零、转动自由，端部锚固允许上拔反力。采用小挠度 Euler–Bernoulli 等效梁；横向刚性，不计轴向伸长、结构振动和水的附加惯性。围护承担水平水压，不将其计入本题等效梁。结构与区内水面调整视为快过程，各时刻按当前水量求准静态平衡。

每区采用一个水平水面，忽略区内水平流动水头损失；两区不直接共用水位。除给定槽口外，隔坎不漏水。忽略蒸发、渗漏及外缘溢流；围护高度不作为本题的约束。各入流已经包含本屋面降雨及邻接屋面的汇水，不能再加一份雨量。停雨后仍按题给关系排水。

## 2. `parameters.json`

`schema_version=1`；`status`、`provenance` 记录附件性质。其余字段如下。

| 路径或字段组 | 单位与含义 |
|---|---|
| `roof.length_m`、`width_m` | 长 6 m、宽 4 m |
| `roof.base_EI_N_m2` | 原梁整条带抗弯刚度，400000 N·m² |
| `roof.dead_load_N_m` | 永久均布线荷载，600 N/m，已含条带宽度 |
| `roof.rho_kg_m3`、`gravity_m_s2` | 水密度 1000 kg/m³，重力加速度 9.81 m/s² |
| `roof.reference`、`beam`、`loads` | 高程、支承、梁模型和荷载约定 |
| `divider.x_m` | 隔坎位置 3 m |
| `divider.height_above_roof_m` | 坎顶高于当地屋面 0.04 m，随中点位移 |
| `divider.notch_width_m` | 槽宽 0.10 m |
| `divider.coefficient_m05_s` | 交换系数 1.6 m^(1/2)/s，配合槽宽及水头的 3/2 次幂得到 m³/s |
| `divider.flow`、`motion` | 与题面相同的可逆分区交换关系及移动约定 |
| `drain.Cd` | 排水口流量系数 0.62，无量纲 |
| `drain.lip_above_roof_m` | 唇口高于当地屋面 0.005 m |
| `drain.original_positions_m` | 原左、右口位置 `[1.2,4.8]`，m |
| `drain.original_area_m2` | 每个原口有效面积 0.0006 m² |
| `drain.left_positions_m`、`right_positions_m` | 可选位置，均自左端量起；分别严格位于左右区 |
| `drain.area_range_m2` | 每口连续可选面积 `[0.0006,0.0012]` m²，包含端点 |
| `drain.flow`、`motion` | 题给自由出流关系；口及唇口随当地屋面移动，下游通大气 |
| `hydraulics` | 水位、分区、时间尺度及忽略项的文字定义 |
| `pricing.currency` | CNY（人民币元） |
| `pricing.relocate_each_cny` | 每改变一口位置增加 450 元；不按移动距离另算 |
| `pricing.area_added_cost_cny_per_m2` | 两口新增有效面积之和乘以 3000000 元/m² |
| `pricing.formula` | 总费用为加固费、移口费及扩口费之和 |

过坎式是本题规定的集中交换关系，已定义双向交换；不要求选手另选淹没堰流公式。该近似没有刻画槽口局部三维流动。不得把水面高程直接当排水水头，或在排水后仍固定原水量。

## 3. `rules.json`

| 字段组 | 说明 |
|---|---|
| `reference_design` | 原梁、原排水口位置和面积，供第二问使用 |
| `duration_min`、`initial_water_m3`、`initial_structure` | 90 分钟；各区初始无水；永久荷载下的初始平衡 |
| `task_1.divider_removed`、`drains_closed` | 第一问暂时拆坎、封口；三种总水量是三个独立试验 |
| `task_1.water_volumes_m3`、`maintained_level_m` | 封闭试验的 0.1、0.5、1.0 m³；外接大水箱维持水位 0.01 m |
| `task_2` | 三工况分别计算，并与固定在初始干梁形状的屋面对照 |
| `design.budgets_cny`、`case_ids`、`fixed_across_cases` | 两档预算 1500、7500 元；每档推荐同一个方案用于 U、L、R |
| `design.limits` | 全过程向下挠度不超过 0.12 m，90 分钟末总水量不超过 0.18 m³ |
| `design.moment_limit` | 用所选加固行的弯矩绝对值限值检查全长、全过程 |
| `task_4.base_design` | 固定第三问 7500 元方案，不为堵塞情形更换组件 |
| `task_4.left_drain_block_min`、`blockage_after` | 第 25 分钟左口完全堵塞，此后保持堵塞，右口不变 |
| `task_4.jack_x_m`、`start_min_range` | 中点单向顶撑，启动时刻在第 30—60 分钟间连续选择 |
| `task_4.target_downward_m`、`upward_rate_mm_min` | 顶部最终距零线向下 0.012 m；启动后向上移动 2 mm/min |
| `task_4.reaction_limit_N` | 向上顶撑反力上限 5000 N |
| `task_4.jack_rule`、`contact` | 题面规定的位移历程与只能向上承压的接触条件 |
| `task_4.retained_limits`、`restriction` | 保留所选梁的挠度、正负弯矩限值；启动前越限仍算越限 |
| `task_4.start_fixed_across_cases` | 同一个启动时刻用于三工况；各工况的初始接触高程由该工况的状态决定 |
| `task_4.observation_end_min`、`remaining_water_requirement_applies` | 堵塞试验也从干态计算到第 90 分钟；报告残余水量，不用 0.18 m³ 判定应急通过 |

顶撑尚未启动时不接触屋盖。启动瞬间先取该工况的中点挠度与 0.012 m 的较大值为 `s0`；支柱顶高程为 `-s(t)`。若屋盖在支柱之上且未接触，反力为零；接触时只能施加向上反力。支柱不改变梁刚度，不增加排水通道，不收取新增费用。反力上限是评价条件，不是让求解器把超过上限的反力直接截成 5000 N。

## 4. `inflows.csv`

UTF-8、逗号分隔、带表头，共 15 行。每种工况各 5 段，从第 0 至 90 分钟无缝覆盖，分段常值。

| 列 | 单位与含义 |
|---|---|
| `case_id` | `U`：对称进水；`L`：较强进水先偏左；`R`：L 的左右镜像 |
| `start_min`、`end_min` | 起止分钟；区间按左闭右开处理，最后一段含观察终点 |
| `left_L_min`、`right_L_min` | 各区规定的进水量，L/min，均非负 |

三工况在每个相同时段的总进水流量均相同，不只是总量相同。空间分配是既定输入，不由排水口面积或局部积水反推。第 45 分钟以后输入为零，继续观察排水至第 90 分钟。计算步长须处理好第 15、25、30、45、60 分钟等输入或运行事件，不跨越事件后继续沿用旧条件。

## 5. `stiffening_options.csv`

共 3 行，单位如下。

| 列 | 含义 |
|---|---|
| `stiffening_id` | B：原梁；S、T：两种全长均匀加固档位 |
| `EI_multiplier` | 对原梁 EI 的倍率，无量纲 |
| `M_limit_N_m` | 正负弯矩绝对值上限，N·m |
| `added_cost_cny` | 加固增费，元；加固增加的自重忽略 |

选型检查程序只核对档位、位置、连续面积范围和总费用，不提供力学计算、设计排序或最优性证书。
