# Problem_001 命题质量审查报告

题目：**低用水片区的余氯保障与有限排放**。审查日期：2026-10-14（北京时间）；任务启动于2026-10-13。本文供教师与仓库审阅者使用，不是参考解答，不发布用户端水质答案、最优排放方案、完整求解步骤或基准求解代码。

## 1. 背景、选题及现实边界

核心矛盾是：用户节水或低入住率降低流量，但既有管道与水箱规模不变；水体更新变慢，余氯变化依赖此前的输入、输运与混合。末梢排放能改变更新过程，但消耗水量、占用共享设施，并不即时把全管段变成入口新水。运行方需要在有限水量下兼顾总体表现、末端长时间不足和有限信息。

EPA 水龄管理与冲洗资料直接支持低用水、末梢及水箱混合问题，同时要求维护压力。题目将实际场景缩减为持续保压的树网、恒水位在线水箱和低速水体更新；不研究停压、水锤、漏损、污染入侵、除垢或全部饮水安全。统一设施水温和认证流量上限是明示的训练假设，不冒充实测温度场或水力压力验证。

候选还包括充电负荷与设备热惯性、热浪避暑空间配置。前者容易落入成熟智能充电模型，后者面临健康效益因果数据不足及2026 ICM E相近主题风险。本题更容易在小规模、完整附件内保留输运、混合、证据、控制与不确定性。具体比较见 [真实赛题调研](research_review.md)及 [独立科学审查](independent_review.md)。

最接近的竞赛主题包括2016 ICM E地区水资源、2017 MCM A坝系替代、2022 MCM B水电分享和2024 ICM D湖泊网络调控；已读题面中的研究对象、状态、控制与本题不同。代表性赛题结构对照和关键词检索范围见调研报告。未发现同结构官方真题，但该结论是有界检索结果，不能保证全球不存在相近问题。

余氯预测、混合模型、水龄管理、监测与冲洗联动均已有研究和工具。本题不宣称这些科学机制或算法首创；原创性在于独立构造的场景、附件、简化指标质疑、共享输运记忆及信息投入比较形成的竞赛任务链。未复制官方题面、第三方数据或论文代码。

## 3. 数学结构与任务依赖

| 任务 | 数学研究重点 | 基础可行路径与局限 | 较深入研究的空间 |
|---|---|---|---|
| 1：可检验模型 | 守恒、初边值闭合、反应与混合的证据支持范围、参数相关性和外推 | 在明确假设下建立动态守恒模型，用分瓶、分工况留出比较预测；不能将瓶试用于识别壁耗，也不能从拟合优度断言结构唯一 | 模型复杂度选择、结构不确定性、混合随流量变化、数值误差与实验信息量 |
| 2：无排放运行 | 变流输运的历史记忆；平均水龄与完整水体信息之间的关系；风险指标的充分性 | 利用第一问模型回放正常期并进入低用水期；在适用条件下研究简化指标，说明误差和不确定性 | 能否用较少状态可靠预测，何时会失效；初态、非恒入口及反应差异改变哪些结论 |
| 3：有限排放 | 动态控制、共享上游影响、水量与不同用户指标的权衡 | 构造合法简易方案作对照，再选择可解释的改进；不要求全局最优或强制所有时刻达标 | 多目标权衡、可行性边界、模型与策略精度、对参数变化稳健的方案 |
| 4：信息价值 | 固定监测配置、误差与时延、非预知反馈、模型失配下的决策可靠性 | 最多两个点、统一预算，设计只读取已到达信息的简单规则，在独立扰动系统回放 | 观测能否区分不确定因素，何时改善决策，布点与控制共同影响，以及监测收益的边界 |

任务2使用任务1建立的状态模型；任务3改变任务2中的流量，从而改变后续水体更新，而非在独立静态表上分配预算；任务4继续服务于相同运行目标，改变可用信息。基础路径不要求专用水力软件、机器学习或一般自适应控制最优性证明。每问均有经试算验证的路径，且不存在唯一预设模型或数值答案。

题面同时给出需求加权不足量、低于目标的用户供水体积分数和各末端最长连续不足时段；排放水不作为用户需求。多个指标的取舍由队伍论证，题面没有藏入唯一权重。监测是否有净收益也是待评价问题，不预设必然改善。

## 4. 数据设计、可复现性与检查

所有附件数值均为合成，生成脚本只包含外部输入、独立瓶试和孤立水箱示踪。没有全网水质观测“真值”、参考策略或网络前向求解器。生成机制公开是复现要求；留出标签用于模型比较与数据使用记录，不是保密盲预测，也不要求恢复隐藏造数参数。使用更复杂生成机制不意味着选手必须采用它。

附件共8个CSV、1个JSON和1份数据字典，CSV合计 **1965行**：10节点、9管段、2水箱、6用户；240小时工况；1440条用户名义需求；162条瓶试；96条示踪。管道几何容积合计 **46.151921 m³**，箱容积 **32 m³**。正常/低用水期总需求均值分别约 **3.595/1.267 m³/h**。这些是输入附件审计结果，不是预测答案。

瓶试覆盖3种水温、2种初始余氯、3个平行瓶和9个时点；108行标定、54行留出。同瓶量测不作为独立重复。最终浓度范围 **0.008—0.861 mg/L**，高于0.005 mg/L检出限。示踪每箱包含2个标定流量和1个较低流量留出工况，记录至200小时；4处缺测仅发生在标定记录，空白有明确标记，不等于零。慢尾可能超出记录区间，预测不应据此排除慢区。

`check_data.py` 的10组检查通过：精确字段与ID、连通无环树、几何容积、完整小时输入、变量范围、1.25倍需求下无排放容量、各预算合法动作存在性、瓶试矩阵与标签、示踪缺测及生成守恒、全部10个文件逐字节重生成。逐文件SHA-256一致。另在临时副本故意修改管容积、删除入口输入、误标留出数据，三次均被明确拒绝；副本未入仓库。

管壁附加有效率只给区间，未伪造识别实验；温度修正规则、量纲及不再乘几何系数明确。需求、源余氯、水温扰动界是压力测试界，不是拟合得到的真实概率分布。数据及字典采用CC0，原创程序MIT，题面与审查CC BY 4.0；第三方资料只引用、不转载。

## 5. 初步求解验证与计算可行性

完整基线程序、状态输出与策略记录只在本次临时 `work/verification` 用于审查，未上传公开仓库，也没有把仓库中的目录当作私有位置。以下只发布非答案性证据，不能据此重建标准策略。

在最终CSV上重新进行了实验模型建立与留出检验：一个合理基线的瓶试留出RMSE约 **0.0039 mg/L**；两个箱的示踪留出RMSE约 **0.0052、0.0078**（归一化浓度）。误差说明存在可计算、可检验路径，不等于所有参数唯一可辨识或对真实系统有效。拟合中观察到参数相关性，保留了第一问对不确定性质的讨论要求。

对最终数据检验了31个合法低复杂度方案，包括无排放对照、三个预算下的简单管理方案。名义无排放运行存在实质不足，有限排放能够改善，多个预算仍形成不同的权衡；没有将“全部已达标”或“所有方案均无效”的数据作为最终附件。未公布预测指标、最优候选或动作时刻。入口、各管容量、操作时段、同时开启数和预算均逐项审计。

动态试算检查了浓度非负、入口/初态浓度上界、水量平衡和耗氯质量平衡。包含最高分辨率检查的累计质量平衡绝对误差小于 **2×10⁻¹⁰ g**，最大稳定性检查量小于0.31。这里的机器精度守恒只是离散实现一致性证据，不代表工程预测精度。

管道空间网格和时间步长分别加密：固定网格下最后一次步长折半的逐小时平均浓度最大变化约 **9.6×10⁻⁵ mg/L**；64到128单元加密的最大变化约 **0.0018 mg/L**，总体不足量呈收敛趋势。但体积分数和最长时段对近阈值的小间隙敏感，不能宣称所有末端的最长时段已精确收敛。题面因此明确要求报告这些指标的数值精度和近阈不确定性，不能用粗逐小时序列直接作精确时长结论。

另对一组合法120 m³方案进行128到256单元加密：逐小时浓度最大变化约 **0.00115 mg/L**，不足量指标绝对差约 **1.7×10⁻⁴**，供水体积分数绝对差约 **6.8×10⁻⁷**。最长连续时段最大差下降到 **0.47 h**，改善但仍应报告近阈值精度限制，不将此结果视为最优性证明。

运行资源的实际测量：31个基础方案批量试算小于1秒、峰值内存约60 MiB；128单元两组回放约9.5秒，256单元单组153600步检查约24.5秒。环境为Python 3.12.14、NumPy 2.3.5、SciPy 1.17.0和Intel Xeon Platinum 8573C Linux容器，仅说明基础规模在普通本科生计算设备上可行，不承诺跨设备相同秒数。优化可以用有限候选与解释性改进完成；高级队伍可研究效率、误差和鲁棒性。

两种基础监测反馈各在三个与设计假设不同的需求、反应、混合及入口/温度情景中回放，对照使用同初态、同预算和同扰动。简单反馈的总体表现不保证稳定优于固定方案，可能改善部分末端而损害其他指标；这是信息价值与策略设计的开放性，不是题目预设答案。真实混合和反应参数不直接交给控制器，当前实际需求与未来状态也不可预读。新增点没有历史或t=0读数；采样从t=1开始、延迟1小时。六个闭环回放重跑后，逐条启动、信息、容量、操作和预算审计全部通过；启动边界修复记录见下一节。

## 6. 发现问题及实际修订记录

| 问题 | 修订与验收依据 |
|---|---|
| “间歇供水”引入未建模停压过程 | 改为持续保压低用水；流量认证边界明示，不暗中要求压力求解 |
| 恒位设施名称容易暗示水量调蓄 | 改为在线水箱，进出流量相等；混合状态仍可不均匀 |
| 初始状态、温度对象和壁耗易混淆 | 给定全设施初余氯和初水龄；统一水温工况；瓶试不含壁耗，墙率量纲明示 |
| 平均水龄结论可能被命题者预设 | 只要求评价充分性及适用条件，不预设长尾或误差方向 |
| 原数据无排放已全达目标，预算任务平凡 | 首轮试算否决该组数据，调整为高反应性合成水质并重生成、重拟合和重跑最终试算；目标值不随结果调高 |
| 数据字典直接展示闭式曲线与份额容易弱化自主建模 | 字典保留机制、假设和复现指向，移除答案型公式；公开造数程序仍透明，题面转向模型比较与外推边界，不把生成参数当隐藏答案 |
| 逐小时或粗网格给最长时段带来虚假精度 | 增加空间与时间加密检查，并要求F与L报告精度和近阈值不确定性 |
| 私下反馈验证错误地允许启动时读取历史/t=0传感器样本 | 独立审查发现后，修正为t=0、1无新增点读数，仅采样时刻≥1且到达时刻≤决策时刻的样本进入控制器；反馈回放须重新通过启动与因果审计，不以旧单一“早于决策”的标志放行 |
| 正式PDF有URL溢出、字体斜体替代及任务跨页 | 改用可断行URL和明确字体配置，任务与附件分别起页；两遍XeLaTeX、文本抽取、页界和全页目视检查 |

高反应性系数是公开合成设计，未引用真实机构作为其测量来源。参数修订是为保障竞赛可研究性，不是证明实际水厂存在某种风险。

## 7. 难度、开放性、评分及保留局限

适合96小时、中高难度本科训练。第一问不是简单描述统计，后续三问必须保留状态记忆、动作反馈和模型验证。允许较简洁模型及透明候选比较，也允许更深入的机制、理论与稳健决策。区分度主要来自假设、证据、推导、数值精度、评价取舍与信息使用；不按算法复杂程度自动加分。

保留局限：合成实验公开机制下的留出不是真正盲测；没有现场用户端观测，预测只能在明确假设下成立；孤立常流试验不能唯一确定任意变流混合；低流下轴向弥散与横向混合近似可能失效；只关注余氯，不能推断病原体、副产物或完整健康风险；最长时段在接近阈值时可能不稳定，应给出精度或区间；没有组织本科生真人96小时试赛。限时训练时建议教师允许简洁的可解释反馈，不要求全局最优。

独立审查复核数据、题面、实际数值证据及反馈启动修复后给出 **87/100**，记录见 `independent_review.md`。主审与独立分数分别保留，不取最高分替代验收。
